# Сценарий демонстрационного видео (до 5 минут)

**Название проекта:** Облачный DevOps-конвейер: от репозитория до production-Kubernetes за 3 команды + AIOps Engine  
**Целевой хронометраж:** 4 минуты 45 секунд.

---

### Блок 1: Введение и правило 3 команд (0:00 – 1:00)
- **Видео:** Открыт чистый терминал Ubuntu.
- **Действие:**
  ```bash
  git clone https://github.com/<team>/mts-devops-platform.git
  cd mts-devops-platform
  make up
  ```
- **Спикер:**  
  *«Здравствуйте! Представляем решение кейса "Облачный DevOps-конвейер". Вся инфраструктура, секреты, чарты и мониторинг разворачиваются ровно за 3 команды без ручных правок. Показываем вывод `make up`: подтянуты статические утилиты, синхронизированы секреты SOPS, отрендерен чарт с Canary-логикой и RED-дашбордом».*

---

### Блок 2: Архитектура, CI/CD и безопасность секретов (1:00 – 2:00)
- **Видео:** Демонстрация файла `secrets/app.enc.yaml` и запуск ротации токена.
- **Действие:**
  ```bash
  make secret-rotate
  ```
- **Спикер:**  
  *«Вся инфраструктура описана кодом: в папке `infra/terraform/openstack` находятся модули для облака МТС. Секреты в Git зашифрованы с помощью SOPS и age. Обратите внимание на уникальную фичу: zero-downtime ротация секретов! Команда `make secret-rotate` переводит сервис в режим dual-token — старый и новый токены принимаются одновременно, поэтому клиенты не получают ни одной ошибки 401».*

---

### Блок 3: Canary-релиз и автоматический откат (2:00 – 3:15)
- **Видео:** Запуск здорового релиза, затем сломанного.
- **Действие 1 (Успех):**
  ```bash
  make release-good
  ```
  *«Команда `make release-good`: трафик плавно переключается 20% -> 50% -> 100% через Ingress-NGINX. Фоновый loadgen обеспечивает постоянный поток метрик в Prometheus».*
- **Действие 2 (Откат):**
  ```bash
  make release-bad
  ```
  *«А теперь симулируем аварийный релиз с ошибками 500. Смотрите: автоматика фиксирует нарушение SLO (ошибок > 5%), прерывает релиз и выполняет мгновенный `helm rollback`! Пользователи защищены».*

---

### Блок 4: Наш козырь — AIOps SRE Copilot (3:15 – 4:15)
- **Видео:** Запуск AIOps диагностики.
- **Действие:**
  ```bash
  make ai-diagnose
  ```
- **Спикер:**  
  *«В отличие от других команд, наш пункт 6 — это не разовый промпт в ChatGPT, а встроенный AIOps Engine! При возникновении сбоя агент автоматически собирает логи пода, события кластера и выдает исчерпывающий SRE Post-Mortem с классификацией P2, объяснением первопричины и готовым Git diff патчем. Время восстановления (MTTR) снизилось с 18 минут до 42 секунд — это подтверждено нашими бенчмарками в `docs/llm/benchmarks.md`».*

---

### Блок 5: Наблюдаемость и итоги (4:15 – 4:45)
- **Видео:** Браузер с Grafana (SLO RED Dashboard) и эндпоинтом `/metrics`.
- **Спикер:**  
  *«В Grafana автоматически загружен наш RED-дашборд с 4 панелями: RPS, доля 5xx ошибок, латентность p95/p99 и распределение Canary/Stable трафика. Настроены 4 алерта PrometheusRule. Конвейер готов к промышленной эксплуатации в облаке МТС. Спасибо за внимание!»*
